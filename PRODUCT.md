# Product

## Register

product

## Platform

web

## Users

Una sola persona registra sus propios entrenamientos de fuerza, principalmente desde el móvil y entre series. Necesita introducir datos con una mano, recuperar una sesión después de cerrar el navegador y consultar entrenamientos anteriores sin depender de la red.

## Product Purpose

Fuerza permite seleccionar ejercicios, registrar series con peso, repeticiones y duración opcional, finalizar una sesión y conservarla localmente. Las sesiones finalizadas se exportan a Markdown estable y se sincronizan con un repositorio privado de GitHub sin un backend propio.

## Brand Personality

Precisa, ágil y robusta. La interfaz debe sentirse minimalista, directa y fiable.

## Anti-references

No debe parecer una aplicación de gimnasio negra y neón, una interfaz de videojuegos, un panel analítico ni una colección de tarjetas decorativas. Evitar gradientes, brillos, glassmorphism y ornamentación que compita con el registro de series.

## Design Principles

- Priorizar el siguiente dato o acción que el usuario necesita durante la sesión.
- Comunicar siempre si los datos están guardados localmente o pendientes de sincronización.
- Mantener controles familiares, táctiles y accesibles incluso con alta densidad de información.
- Conservar el trabajo del usuario ante cierres, pérdida de red y errores remotos.
- Utilizar el color para acciones y estados, nunca como decoración.

## Accessibility & Inclusion

Contraste WCAG AA, objetivos táctiles de al menos 44 × 44 px, navegación completa con teclado, foco visible, etiquetas persistentes y estados expresados con texto además de color. Se respeta `prefers-reduced-motion` y la aplicación funciona desde 360 px de ancho.
